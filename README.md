# 🎓 CampusCare AI - Smart Campus Support Portal

CampusCare AI is a modern web-based campus support portal that enables students to raise complaints and track their status while providing administrators with a centralized dashboard to manage, monitor, and resolve support tickets efficiently. The system also integrates an AI chatbot to provide instant assistance for common campus-related queries.

---

## 🚀 Features

### 👨‍🎓 Student Portal
- Secure Login
- Submit Support Tickets
- Set Complaint Priority (Low, Medium, High)
- Upload Images as Evidence
- Generate Unique Ticket IDs
- Track Complaint Status
- AI Chatbot Support
- Responsive Dashboard

### 👨‍💼 Admin Portal
- Administrator Login
- View All Complaints
- Search Tickets
- Update Complaint Status
- Delete Complaints
- View Complete Complaint Details
- Dashboard Statistics
  - Total Tickets
  - Pending Tickets
  - Solved Tickets
